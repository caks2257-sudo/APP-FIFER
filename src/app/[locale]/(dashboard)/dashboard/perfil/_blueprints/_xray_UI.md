- Etiquetas en gris técnico `#94A3B8`, mayúsculas de tracking suave.
- Campos: fondo `#111827`, borde `#1E293B`, texto `#F9FAFB`.
- **Electric Yellow** (`#EAB308`) reservado para:
  - Botón primario **Guardar expediente** (único CTA amarillo en el módulo).

  - Mensajes de error de validación (estado activo de corrección), no para decoración general.
